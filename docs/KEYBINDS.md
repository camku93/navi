# Keybinds

## Windows

| Key | Action |
| --- | --- |
| Alt+j / Alt+k | Focus next / previous window |
| Alt+Tab | Focus next window |
| Alt+z | Zoom (swap focused window into master) |
| Alt+Shift+c | Close focused window |
| Alt+Shift+space | Toggle floating for focused window |
| Alt+Shift+f | Toggle fullscreen for focused window |
| Alt+i / Alt+d | More / fewer windows in master area |
| Alt+h / Alt+l | Shrink / grow master area |

## Layouts and bar

| Key | Action |
| --- | --- |
| Alt+t | Tile layout |
| Alt+f | Floating layout |
| Alt+m | Monocle layout |
| Alt+space | Toggle previous layout |
| Alt+b | Toggle bar visibility |
| Super+Shift+\ | Switch statusbar position |

## Tags (workspaces)

| Key | Action |
| --- | --- |
| Alt+1 through Alt+9 | View tag N |
| Alt+Ctrl+1-9 | Toggle view of tag N |
| Alt+Shift+1-9 | Send window to tag N |
| Alt+Ctrl+Shift+1-9 | Toggle window on tag N |
| Alt+0 | View all tags |
| Alt+Shift+0 | Send window to all tags |

## Monitors

| Key | Action |
| --- | --- |
| Alt+comma / Alt+period | Focus previous / next monitor |
| Alt+Shift+comma / Alt+Shift+period | Send window to previous / next monitor |
| Super+F4 | Display switch (laptop / external / extend / mirror) |

## Terminals

| Key | Action |
| --- | --- |
| Alt+Return or Super+Return | Open terminal |
| Alt+Shift+Return or Super+Shift+Return | Master terminal: show / hide a floating terminal |

## Session

| Key | Action |
| --- | --- |
| Super+l | Lock screen |
| Alt+Shift+q | Quit dwm |

## Copy and paste

| Key | Action |
| --- | --- |
| Alt+c / Alt+Shift+c | Copy selection to clipboard |
| Alt+v / Alt+Shift+v | Paste from clipboard |
| Shift+Insert | Paste |
| Alt+Shift+l | Open URL under selection |
| Alt+y | Copy URL under selection |
| Alt+o | Copy last command output |

## Scrolling

| Key | Action |
| --- | --- |
| Alt+Up | Scroll up one line |
| Alt+Down | Scroll down one line |
| Alt+u / Shift+PageUp | Scroll up one page |
| Shift+PageDown | Scroll down one page |

## Font size

| Key | Action |
| --- | --- |
| Alt+Shift+Up / Alt+Shift+K | Increase font size |
| Alt+Shift+Down / Alt+Shift+J | Decrease font size |
| Alt+Shift+U | Increase font size (larger step) |
| Alt+Shift+D | Decrease font size (larger step) |
| Alt+Shift+Home | Reset font size |

## Transparency

| Key | Action |
| --- | --- |
| Alt+s | Decrease transparency |
| Alt+a | Increase transparency |

## Wallpaper

| Key | Action |
| --- | --- |
| b (in lf) | Set the selected image as your wallpaper |
| setbg image.jpg | Set a wallpaper from the terminal |
