# Keybinds

## Windows

| Key | Action |
| --- | --- |
| Super+j / Super+k | Focus next / previous window |
| Super+Tab | Focus next window |
| Super+z | Zoom (swap focused window into master) |
| Super+Shift+c | Close focused window |
| Super+Shift+space | Toggle floating for focused window |
| Super+Shift+f | Toggle fullscreen for focused window |
| Super+i / Super+d | More / fewer windows in master area |
| Super+h / Super+l | Shrink / grow master area |

## Layouts and bar

| Key | Action |
| --- | --- |
| Super+t | Tile layout |
| Super+Shift+t | Centered master layout |
| Super+f | Floating layout |
| Super+Shift+m | Monocle layout |
| Super+space | Toggle previous layout |
| Super+b | Toggle bar visibility |
| Super+Shift+b | Switch statusbar position |

## Tags (workspaces)

| Key | Action |
| --- | --- |
| Super+1 through Super+9 | View tag N |
| Super+Ctrl+1-9 | Toggle view of tag N |
| Super+Shift+1-9 | Send window to tag N |
| Super+Ctrl+Shift+1-9 | Toggle window on tag N |
| Super+0 | View all tags |
| Super+Shift+0 | Send window to all tags |

## Monitors

| Key | Action |
| --- | --- |
| Super+comma / Super+period | Focus previous / next monitor |
| Super+Shift+comma / Super+Shift+period | Send window to previous / next monitor |
| Super+F4 | Display switch (one screen / extend / mirror) |

## Terminals

| Key | Action |
| --- | --- |
| Super+Return | Open terminal |
| Super+Shift+Return | Master terminal: show / hide a floating terminal |

## Session

| Key | Action |
| --- | --- |
| Super+Escape | Lock screen |
| Super+Shift+q | Log out |

## Copy and paste

| Key | Action |
| --- | --- |
| Alt+c / Alt+Shift+c | Copy selection to clipboard |
| Alt+v / Alt+Shift+v | Paste from clipboard |
| Shift+Insert | Paste |
| Alt+Shift+l | Open URL under selection |
| Alt+y | Copy URL under selection |
| Alt+o | Copy last command output |

## Scrolling

| Key | Action |
| --- | --- |
| Alt+Up | Scroll up one line |
| Alt+Down | Scroll down one line |
| Alt+u / Shift+PageUp | Scroll up one page |
| Shift+PageDown | Scroll down one page |

## Font size

| Key | Action |
| --- | --- |
| Alt+Shift+Up / Alt+Shift+K | Increase font size |
| Alt+Shift+Down / Alt+Shift+J | Decrease font size |
| Alt+Shift+U | Increase font size (larger step) |
| Alt+Shift+D | Decrease font size (larger step) |
| Alt+Shift+Home | Reset font size |

## Transparency

| Key | Action |
| --- | --- |
| Alt+s | Decrease transparency |
| Alt+a | Increase transparency |

## Wallpaper

| Key | Action |
| --- | --- |
| b (in lf) | Set the selected image as your wallpaper |
| setbg image.jpg | Set a wallpaper from the terminal |
